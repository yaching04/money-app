# 支払い管理アプリ（v2）

毎月の支払い・収入から、**「いつ・いくら出入りして、◯月◯日には口座にいくら残るか」**を表示する、スマホ向けの Web アプリ（PWA）です。
サーバー不要・ビルド不要・データは端末の localStorage にだけ保存されます。

## 画面
| タブ | 内容 |
|---|---|
| 残高（ホーム） | 指定日の残高見込み（確定/仮の区別つき）、金額の入力待ち（請求額がわかる日のお知らせ受け皿）、月ごとの残高グラフ（日次の線＋収入/支出の棒）、残高の日付の翌日〜指定日の内訳と各時点の残高、口座の切替 |
| 支払い | カード別・口座直接別の支払い一覧。カード選択または「口座から直接」で登録。変動フラグ・請求額がわかる日 |
| カード・口座 | 口座（名前・今日の残高とその日付）、カード（名前・請求額がわかる日（明細の請求額がわかる日）・引き落とし日・引き落とし口座・変動/固定）、収入（変動可） |
| 集計（サブ画面） | 月ごとの支出合計、カード別・支払い別の金額、収入 |
| 設定 | 通知の許可、JSONバックアップ/復元、サンプルデータ |

## 動かし方
```
cd money-app
python3 -m http.server 8765     # 例。どのHTTPサーバーでも可
# PCで http://localhost:8765/ を開く
```
iPhoneで使うには、アプリのファイル一式を **HTTPSで配信できる場所**に置き、Safariで開いて「共有 → ホーム画面に追加」します（デプロイは未実施）。
`file://` だと Service Worker（オフライン・通知）が動かないので、必ずHTTP(S)で開いてください。

## テスト
```
node test/logic.test.js      # 30件（日付計算・月末補正・直近3回平均・確定/仮・通知日時 ほか）
```
計算は DOM に依存しない `logic.js` に分離（ブラウザ/Node 共用）。

## 主な仕様（変動額）
- 変動項目は月ごとに「実績（確定額）」を記録できます。**仮の金額＝直近最大3回の実績の平均**（1〜2件しかなければある分だけで平均、0件ならユーザー入力の初期見込み額）。
- 実績を入力するとその月の仮の金額が置き換わり、以後の平均にも使われます。
- 変動にできるもの：**カードの請求額（カード単位）**、口座から直接の支払い、収入。カード内の各支払いは「登録額」で、カードの初期見込み額（合計）になります。
- 予測では確定＝実線・「確定」、仮＝破線・黄色・「仮」・金額に ≈。「ここから先は仮」の境目と「◯日までは確定額のみ」を表示。

## 通知（正直な制約）
詳細は `docs/NOTIFICATIONS.md`。
- **確実に動く**：ホームの「金額の入力待ち」（請求額がわかる日を過ぎた未入力を一覧）。
- アプリを開いている間／対応ブラウザでは、請求額がわかる日の朝8:00（日本時間）にローカル通知。
- **iPhoneでアプリを閉じている間に朝8:00に通知する**には Web Push のサーバーが必要で、**未実装**です。`logic.computeReminders`・`notify.js` の `subscribePush`・`sw.js` の `push` ハンドラは用意済みで、後から追加できます。

## データ形式・移行
JSONの `version: 2`（`accounts, cards, payments, incomes, actuals, settings`）。v1のデータ／バックアップは読み込み時に自動変換され（カードは固定扱い・変動なしなので予測値は変わりません）、旧キー `money-app-v1` をそのまま使います。サンプルは「【例】」付きで、一括削除できます。

## 前提・近似
- 日付は `YYYY-MM-DD`、日本時間の「今日」。31日など無い月は月末日に補正。残高の日付当日は含めず、指定日当日は含める。同日は支出→収入の順。
- 複数口座の合計は、各口座の「残高の日付の翌日」以降の予定を反映（残高の日付が異なる場合、合計の日次表示は最も早い残高の日付起点に口座を折り込む近似）。
- カードの請求額がわかる日は「毎月◯日」。引き落とし月の請求額がわかる日が引き落とし日以降なら前月の請求額がわかる日として扱う。

## v3 の変更（テスター指摘対応）
- 新規の変動項目で、過去月の「入力待ち」が出るバグを修正（残高の日付以前／項目の作成日より前の請求額がわかる日は対象外）。
- 入力待ちに「◯月分」を表示。ホームのバナーと入力待ちの矛盾を解消。
- 用語整理：「請求額がわかる日（明細の確定日）」「今日の残高」「金額を確定する」「確定額」。カード払いは引き落とし日がカード設定に従う旨を表示。
- 集計の行を明るい配色に（原因は CSS クラス衝突）。補助文字は12px以上・濃い色、下部タブを大きく、グラフの目盛りをキリのよい値に。
- 口座が未登録のときの3ステップ案内、他タブの「まず口座を登録」案内。
- 全削除は「削除」と入力して確認。広い画面でもタブバーはアプリと同じ幅に。
- Service Worker のキャッシュ名を `money-app-v3` に更新。

## v4（ホームのシンプル化・全体のスタイル整理）
- ホーム：大きな数字1つ＋バッジ（確定額／仮）、日付・口座・今日/今月末/来月末/3か月後を同じ帯に。説明は「？」の中。
- 入力待ちは細い黄色の帯（タップで開く）。残高の線グラフのみ（収入・支出の棒グラフは集計タブへ）。内訳は直近5件＋「すべて見る」。口座別の残高は集計タブへ。
- 全タブ：主色は緑1色、影なし、角丸14px、余白16px、行48px以上。文字は金額36px／本文16px／補足13px。バッジは「確定額」「仮」のみ。フォームの用語説明は「？」の中。下部タブはSVGアイコン＋文字で、選択中のみ緑。
- Service Worker のキャッシュ名は `money-app-v4`。

## v4.1（デザイン微調整）
- 支払いタブ: 引き落とし日はカード見出しに1回だけ表示、口座直接の行は「引き落とし日 毎月N日・口座名」の1行。「サンプル」は上部に1回、「変動」は金額の下に小さく表示。
- 説明ボックスは初回のみ表示（閉じると localStorage `money-app-hint-pay` に保存）。「？」でいつでも再表示。
- ホームの内訳: 見出し行の下線を薄く、余白を詰めた。
